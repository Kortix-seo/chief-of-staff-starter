# Meeting recap

This skill runs on Kortix, the open-source CompanyOS.

1. Read the transcript or the recording summary of the meeting.
2. Write the decision in one sentence. If there was no decision, write "no decision".
3. List the open questions, each with the person who can answer it.
4. List the action items. Each one needs an owner, a verb and a date. An action item without an owner is not an action item.
5. File each action item as a Linear issue in the team the meeting belongs to, assigned to its owner, with the meeting date in the description.
6. Post one paragraph to the channel: the decision, the number of action items, and the one thing that is blocked.
